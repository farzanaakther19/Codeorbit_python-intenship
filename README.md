# Python Programming Projects

**Internship:** CodeOrbit Tech
**Domain:** Python Programming
**Tools:** Python 3, Visual Studio Code, GitHub

## Introduction

This repository contains three Python applications developed as part of the CodeOrbit Tech Python Programming Internship. The projects demonstrate fundamental programming concepts, logical thinking, error handling, and file management.

## Project Details

### Project 1: Basic Calculator

A command-line application designed to perform basic arithmetic calculations.

**Functionalities:**

* Addition, subtraction, multiplication, and division.
* Accepts numeric input from users.
* Handles invalid numeric input.
* Prevents division by zero.
* Displays the calculated result.

**Source File:** `calculator.py`

### Project 2: Number Guessing Game

An interactive game in which the computer selects a random number between 1 and 100, and the player attempts to guess it.

**Functionalities:**

* Generates a random number.
* Provides hints for guesses that are too high or too low.
* Tracks the number of valid attempts.
* Validates user input.
* Displays a success message when the number is guessed correctly.

**Source File:** `guessing_game.py`

### Project 3: To-Do List Application

A command-line task management system that helps users organize and manage daily activities.

**Functionalities:**

* Add new tasks.
* Display existing tasks.
* Remove tasks using their numbers.
* Save tasks in a text file.
* Retrieve previously saved tasks when the application starts.
* Handle invalid menu selections and task numbers.

**Source File:** `todo_list.py`

**Data File:** `tasks.txt` (created when tasks are saved).

## Software Requirements

* Python 3.x
* Visual Studio Code or another Python editor
* A terminal or command prompt

## Installation and Execution

### Step 1: Download the Repository

Clone the repository using Git:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Alternatively, download the repository as a ZIP file and extract it.

### Step 2: Open the Project

Open the extracted folder in Visual Studio Code.

### Step 3: Execute the Applications

Run the required Python file from the terminal.

**Calculator:**

```bash
python calculator.py
```

**Number Guessing Game:**

```bash
python guessing_game.py
```

**To-Do List Application:**

```bash
python todo_list.py
```

On Windows, use `py` instead of `python` if necessary.
